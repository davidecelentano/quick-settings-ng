# Upstream provenance

Quick Settings NG is a new GNOME Shell extension that incorporates,
ports, rewrites, and hardens concepts and code originating from the
projects listed below.

## Quick Settings Tweaks

Repository:
https://github.com/jstockdale/quick-settings-tweaks

Baseline:
98ce22a

Reviewed pull requests:

- PR #7
  - 2188fdc
  - 5550603

- PR #8
  - b5fa296
  - aa18c94

Relevant donor functionality includes Quick Settings layout customization,
media controls, volume mixer, menu effects, and supporting utilities. Notification
and weather implementations were audited but are intentionally not part of QSNG
because GNOME already exposes those surfaces in the date menu.

## Privacy Menu Extension

Repository:
https://github.com/stuarthayhurst/privacy-menu-extension

Baseline:
f33a3e8

Relevant functionality includes privacy controls for location,
camera, and microphone.
